# Prompt de IA - Framework COSTAR

Este arquivo contém o prompt estruturado utilizado para gerar a lógica matemática de resumo de gastos (soma de entradas vs. saídas) para a aplicação financeira.

---

### 📝 Prompt COSTAR

* **C (Context - Contexto):**  
  Estou desenvolvendo uma aplicação de controle financeiro pessoal que utiliza o Firebase Firestore como banco de dados em tempo real e JavaScript (ES6+).

* **O (Objective - Objetivo):**  
  Criar uma função em JavaScript que receba uma lista de transações do Firestore, filtre os lançamentos por tipo ("receita" ou "despesa"), calcule o total de entradas, o total de saídas e o saldo final (entradas - saídas).

* **S (Style - Estilo):**  
  Código limpo, bem comentado, legível e sem dependências externas ou bibliotecas de terceiros.

* **T (Tone - Tom):**  
  Técnico, profissional e direto ao ponto.

* **A (Audience - Público-alvo):**  
  Desenvolvedor JavaScript Junior.

* **R (Response - Resposta esperada):**  
  Explicação passo a passo da lógica matemática utilizada acompanhada do bloco de código JavaScript com sintaxe ES6+ (Arrow Functions e Desestruturação).
